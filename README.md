# Bestemshe-Engine (archived)

This was the working copy of the ResMLP training code used on the rented GPU machine. The maintained version lives in [ansarzeinulla/Bestemshe](https://github.com/ansarzeinulla/Bestemshe), under `training/`. The full training run (54 checkpoints plus the final one, evaluations of 38 of them, and the run scripts) is archived on Hugging Face as `ansarzeinulla/bestemshe-engine`; that repository is private for now.

`server.md` (in Russian) lists the commands used on that machine.
